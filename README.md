# وفاق | Wefaq

تطبيق عربي قيد التطوير يساعد المخطوبين على فتح حوارات واضحة ومحترمة. المشروع يبدأ بتطبيق Flutter؛ الموقع والخادم ولوحة الإدارة مراحل مستقبلية.

> **الحالة:** المشروع غير جاهز للنشر بعد. الأسئلة والأنشطة لم تُراجع شرعيًا وأسريًا. يوجد تفعيل محلي قيد التطوير للنسخة المباشرة من Android، ولا يوجد دفع في التطبيق. يلزم إعداد مفتاح التحقق واختبار الأجهزة والاستعادة ومراجعة المحتوى قبل البيع.

لخطة الإنتاج الكاملة وتسليم العمل للـ agents، راجع [خطة الإنتاج](docs/production-plan.md).

## المتطلبات

- Flutter **3.47.9** (ويتضمن Dart 3.13) أو إصدار متوافق؛ انظر `pubspec.yaml`.
- Android SDK ومحاكي أو جهاز Android لتشغيل Android.
- macOS وXcode وإعدادات التوقيع لتشغيل وبناء iOS.
- اتصال بالإنترنت لتنزيل الاعتماديات أول مرة.

## التشغيل والتحقق

انسخ `.env.example` إلى `.env` قبل البناء واضبط القيم العامة المطلوبة. يُضمّن الملف في التطبيق ويمكن لأي مستخدم قراءته؛ لا تضع فيه مفاتيح خاصة أو رموز إدارة أو أي أسرار. ملف `.env` المحلي مستثنى من Git.

```bash
flutter doctor
flutter pub get
flutter devices
flutter run
```

اختر جهازًا محددًا عند الحاجة باستخدام `flutter run -d <device-id>`. التطبيق يتطلب مفتاح تحقق عام عبر `--dart-define=WEFAQ_LICENSE_PUBLIC_KEY=<public-key>`؛ بدون المفتاح تظهر شاشة إعداد التفعيل ولا تُفتح الميزات. راجع [تصميم التفعيل](docs/offline-first-release-design.md) لإعداد أداة إصدار الأكواد وحدودها.

تدعم نسخة Android إصدار رابط تفعيل موقّع، لكنه يحتاج دومين HTTPS تحت إدارتك وملف ربط Android وإعداد الدومين في نسختَي إعداد Android وDart كما هو موضح في تصميم التفعيل. ميزة Universal Links على iOS لم تُجهز بعد.

للتحقق قبل رفع التغييرات:

```bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
```

فحص iOS يتطلب جهاز macOS وإعدادات Xcode. يوجد فحص آلي للتنسيق والتحليل والاختبارات في GitHub Actions.

## البنية

```text
lib/
  core/                 الهوية والثيم المشترك
  features/home/        شاشة البداية
  features/sessions/    إعداد الجلسة، أمثلة الأسئلة، والتقدم
  main.dart             نقطة الدخول واللغة
assets/fonts/           خط Cairo وترخيصه
assets/images/          تصور الأيقونة المختار
android/ و ios/         مشاريع المنصات
```

الواجهة عربية وRTL باستخدام توطين Flutter، وخط Cairo مرفق محليًا ليعمل دون تحميل وقت التشغيل. ترخيص الخط في `assets/fonts/OFL.txt`. أيقونات تشغيل Android وiOS مشتقة من صورة الأيقونة المختارة؛ الصورة تصور مولّد وليست ملف شعار متجهي نهائيًا.

## خيارات الجلسة وتجنب التكرار

يمكن اختيار عدد سريع 5 أو 10 أو 20 أو 30 أو 50، أو ضبط العدد يدويًا ضمن المتاح. خيار «تجنب الأسئلة السابقة» يستبعد أسئلة الجلسات المسجلة على الجهاز، ويمنع بدء الجلسة عند عدم وجود أسئلة جديدة كافية. تُسجل جميع أسئلة الجلسة عند بدايتها، حتى إن لم يصل المستخدم إليها. السجل محلي لهذا الجهاز ويُفقد عند إزالة بيانات التطبيق؛ لا تتم مزامنته مع جهاز آخر. الإصدارات السابقة احتفظت بآخر 100 معرّف فقط، ولا يمكن استعادة السجل الأقدم المفقود.

## تحديث الأسئلة

يمكن تحديث الأسئلة يدويًا من المساعدة باستخدام `WEFAQ_QUESTIONS_API_URL` من ملف `.env` في جذر المشروع (ويمكن تجاوزه عبر `--dart-define=WEFAQ_QUESTIONS_API_URL=...` وقت البناء). تبقى آخر نسخة صالحة محفوظة للاستخدام دون إنترنت، ويُرفض التحديث غير الصالح أو الذي يحذف أسئلة موجودة. يجب إنهاء أو حذف الجلسة المحفوظة قبل التحديث. الخادم المرفق في `backend/` منشور على Vercel؛ راجع [عقد الأسئلة](docs/questions-api-contract.md).

## الألعاب وDISC

يوفر شريط التنقل الوصول للرئيسية والأنشطة والمفضلة والمساعدة. تشمل الأنشطة بطاقات مواقف وترتيب أولويات؛ محتواها تجريبي ويحتاج مراجعة شرعية وأسرية. يوجد تمرين أصلي مستوحى من أنماط DISC للاستكشاف وفتح الحوار، وليس اختبار DISC رسميًا أو معتمدًا ولا تشخيصًا أو مقياسًا للتوافق. يختار المستخدم إجابة لكل سؤال ويمكنه كتابة ملاحظة اختيارية لا تدخل في حساب النتيجة. تبقى الإجابات والملاحظات في ذاكرة الشاشة فقط وتُفقد عند الخروج أو إعادة التمرين؛ لا تُرسل لخادم أو تُحفظ بواسطة التطبيق.

## الاتجاه والخطوات القادمة

- توسيع الجلسات وتحسينها بعد اختبار تجربة المستخدم؛ الجلسة والمفضلة تُخزنان محليًا عند تشغيل التطبيق، ويُحذف تقدم الجلسة عند إنهائها صراحةً. يلزم اختبار الاستعادة على الأجهزة.
- إعداد بنك محتوى ومراجعته شرعيًا وأسريًا قبل نشره؛ لا نحفظ إجابات المستخدم افتراضيًا.
- تصميم خادم وتراخيص وربط الأجهزة وعدّ الجلسات بشكل آمن قبل التنفيذ. لا تعتمد على معرّف التثبيت كحماية مطلقة.
- مراجعة سياسة المتجر وقناة التوزيع ومتطلبات الخصوصية والقانون قبل بناء الدفع أو إطلاق المنتج.
- مراجعة اسم الحزمة `com.wefaq.wefaq`، والشعار والاسم التجاري، وإعداد التوقيع قبل النشر.
- تصميم الموقع ولوحة الإدارة لاحقًا وفق نفس الهوية.

## الخصوصية والأمان

النسخة الحالية تحفظ تقدم الجلسة والمفضلة محليًا ولا تسجل إجابات الحوار، وتحفظ بيانات التفعيل ومعرّف التثبيت في التخزين الآمن على الجهاز. تحديث الأسئلة اليدوي يتصل بخادم HTTPS عند ضبطه؛ لا يرسل التطبيق في طلب التحديث معرّف التثبيت أو كود التفعيل أو الإجابات. لا توجد حسابات أو دفع في التطبيق. قد تحتوي الملاحظات التي يكتبها المستخدم على بيانات شخصية. لا تضع أسرارًا أو بيانات عملاء في المستودع. تتطلب الميزات مراجعة أمنية وقانونية وسياسة خصوصية مناسبة قبل الإطلاق.
