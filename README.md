# وفاق | Wefaq

تطبيق عربي قيد التطوير يساعد المخطوبين على فتح حوارات واضحة ومحترمة. المشروع يبدأ بتطبيق Flutter؛ الموقع والخادم ولوحة الإدارة مراحل مستقبلية.

> **الحالة:** هذا أساس أولي فقط، وليس منتجًا جاهزًا للنشر. توجد جلسات محلية بأسئلة تجريبية غير مراجعة؛ لا توجد اشتراكات أو دفع أو تفعيل في هذه النسخة. يجب مراجعة المحتوى من متخصص شرعي وأسري قبل نشره.

## المتطلبات

- Flutter **3.47.9** (ويتضمن Dart 3.13) أو إصدار متوافق؛ انظر `pubspec.yaml`.
- Android SDK ومحاكي أو جهاز Android لتشغيل Android.
- macOS وXcode وإعدادات التوقيع لتشغيل وبناء iOS.
- اتصال بالإنترنت لتنزيل الاعتماديات أول مرة.

## التشغيل والتحقق

```bash
flutter doctor
flutter pub get
flutter devices
flutter run
```

اختر جهازًا محددًا عند الحاجة باستخدام `flutter run -d <device-id>`. للتحقق قبل رفع التغييرات:

```bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
```

فحص iOS يتطلب جهاز macOS وإعدادات Xcode. يوجد فحص آلي للتنسيق والتحليل والاختبارات في GitHub Actions.

## البنية

```text
lib/
  core/                 الهوية والثيم المشترك
  features/home/        شاشة البداية
  features/sessions/    إعداد الجلسة، أمثلة الأسئلة، والتقدم
  main.dart             نقطة الدخول واللغة
assets/fonts/           خط Cairo وترخيصه
assets/images/          تصور الأيقونة المختار
android/ و ios/         مشاريع المنصات
```

الواجهة عربية وRTL باستخدام توطين Flutter، وخط Cairo مرفق محليًا ليعمل دون تحميل وقت التشغيل. ترخيص الخط في `assets/fonts/OFL.txt`. صورة الأيقونة تصور مولّد وليست ملف شعار متجهي نهائيًا؛ أيقونات التشغيل الافتراضية للمنصات لم تُستبدل بعد.

## الاتجاه والخطوات القادمة

- توسيع الجلسات وتحسينها بعد اختبار تجربة المستخدم؛ الجلسة الحالية لا تُحفظ عند الخروج أو إغلاق التطبيق.
- إعداد بنك محتوى ومراجعته شرعيًا وأسريًا قبل نشره؛ لا نحفظ إجابات المستخدم افتراضيًا.
- تصميم خادم وتراخيص وربط الأجهزة وعدّ الجلسات بشكل آمن قبل التنفيذ. لا تعتمد على معرّف التثبيت كحماية مطلقة.
- مراجعة سياسة المتجر وقناة التوزيع ومتطلبات الخصوصية والقانون قبل بناء الدفع أو إطلاق المنتج.
- مراجعة اسم الحزمة `com.wefaq.wefaq`، والشعار والاسم التجاري، وإعداد التوقيع قبل النشر.
- تصميم الموقع ولوحة الإدارة لاحقًا وفق نفس الهوية.

## الخصوصية والأمان

النسخة الحالية لا تحفظ تقدم الجلسة أو إجاباتها، ولا تنشئ حسابات ولا تجمع إجابات أو تنفذ دفعًا أو اتصالات بخادم. لا تضع أسرارًا أو بيانات عملاء في المستودع. تتطلب أي ميزات مستقبلية مراجعة أمنية وقانونية وسياسة خصوصية مناسبة قبل الإطلاق.
