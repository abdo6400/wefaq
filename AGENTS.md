# Project agent instructions

## Complete the agreed plan

When the user authorizes a plan or asks an agent to carry out a task, the agent
must continue through all authorized, necessary implementation, integration,
documentation, and verification work until the agreed outcome is complete.
Do not stop after an initial phase, prototype, plan, or passing focused test and
present it as the completed work. Preserve the agreed objective across turns and
context compaction, and keep the user informed during longer work.

If genuinely blocked by missing user decisions, required external access, or an
unavailable system, perform all independent work first, describe the exact
blocker and unfinished work, and request only what is necessary. Do not invent
approval or claim that external review, production readiness, or testing was
completed when it was not. Follow higher-priority instructions, including any
limits on permissions, safety, and available tools.
